
# 克隆项目
git clone https://github.com/wddqing/spug.git
cd spug

# 创建运行环境
## ubuntu安装依赖
sudo apt install python3-dev gcc libldap2-dev rsync sshfs
sudo apt install libmariadb-dev 或者 sudo apt install libmysqlclient-dev （libmysqlclient-dev 能安装 pip install mysqlclient 成功）

Ubuntu 20.04+ 默认把 MySQL 换成 MariaDB，因此 libmariadb-dev 就能满足；
如果你坚持原版 MySQL，可换 sudo apt install libmysqlclient-dev。

## 创建虚拟环境
cd /data/spug/spug_api
python3 -m venv venv
source venv/bin/activate

# 安装python包
pip install -U pip setuptools -i https://pypi.tuna.tsinghua.edu.cn/simple/
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
pip install gunicorn mysqlclient -i https://pypi.tuna.tsinghua.edu.cn/simple/
